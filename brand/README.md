# Pharoam brand

The chosen identity is the **Line P seal** in the **Graphite and channel** colour scheme. Open `index.html` to see the brand board.

## Files

| File | Use |
| --- | --- |
| `seal.svg` | The primary identifier: graphite seal, light lines, gold lamp and beam |
| `seal-reversed.svg` | On dark grounds |
| `seal-outline.svg` | Print and single-colour use |
| `seal-channel.svg` | Marketing only |
| `wordmark.svg`, `wordmark-reversed.svg` | The open line P as the first letter, then "haroam" in Figtree 800, outlined to paths |
| `line-p.svg`, `line-p-reversed.svg` | The open line P on its own, for inline and small use |
| `app-icon.svg` | Square app icon; platforms round the corners |
| `favicon.svg` | 32 and 48 px |
| `favicon-16.svg` | 16 px: one heavy P, the lamp and the beam |

## Colours

| Name | Hex | Role |
| --- | --- | --- |
| Graphite | `#1b1d1f` | The brand: seal, wordmark, text, the one filled button |
| Channel | `#2c6488` | The one hue for data: evidence, links, main data, focus (6.4:1 on white) |
| Paper | `#f3f3f3` | Page ground |
| Fog | `#e5e5e5` | Tonal panels |
| Lamp | `#f2b632` | The lamp and beam in the logo, a highlight wash; never text or status |

## Rules

- The seal is the identifier. In the wordmark, the open line P replaces the first letter. Never put the seal inside the word.
- Clear space around the seal is a quarter of its diameter. The smallest seal is 16 px (use `favicon-16.svg`). The smallest wordmark is 96 px wide.
- The lamp is always `#f2b632`. Don't recolour it, add more rays, animate it, or set the mark in a gradient.
- Hosting organisations can't change, tint or co-brand the identity.

## Fonts

Figtree (SIL Open Font Licence) is self-hosted in `../assets/fonts`. The wordmark is outlined, so it never depends on the font being installed.
